# 录制控制与双机同步

## 操作

恢复项目并确认相机已采集后，在“双机同步”页检查主从角色、同步对象和状态，再执行一键时间戳同步。连接同步线是硬件前提。同步会重新核对当前后台和相机，拒绝在任意文件录制状态不明或正在录制时重置时钟；不会因旧的 SYNC_OK 显示而假报本次成功。

“录制控制”从当前 DV 后台读取模块和连线，不依赖特定 XML、模块数量或相机编号。当前支持官方 dv_output_file 模块；其他写出类型会显示为不支持。勾选一个模块可单独录制，勾选多个可联合启动；未选中的模块不会跟随启停。

开始前检查所选模块确实空闲、输入端口及上游数据源可用、相机身份一致、目录可写、文件前缀有效以及本地磁盘空间。多相机数据源默认要求同步状态及时间偏移一致；只有明确取消对应选项才跳过此项，开始录制本身不会执行同步。

每次录制在原有前缀后加入 __DVC_<随机标识>_<序号>，避免快速重录或多个模块前缀相同而覆盖文件；目录不变。生成的前缀会保留在当前 DV 配置中，保存项目也会保存它；下次通过 Companion 录制会替换旧标识，不会反复叠加。

“停止所选录制”只停止勾选模块，等待后台确认已完成正常关闭。部分启动失败时，会核对身份并正常停止本次尝试启动的模块，保留录制文件；无法确认时显示待确认，不会强杀进程。操作期间应避免同时在 DV 中修改这些模块。

## 时间精度与诊断

联合启动将所选控制指令放入一次网络写入，减少人工逐个点击的间隔。DV 没有原子批量启动接口，后台仍逐个处理模块，因此不能保证文件的第一条事件或第一帧同时出现。时间戳同步也不等同于帧曝光硬件同步；双目分析应使用数据时间戳和两路共有的时间区间。

开始成功表示后台报告正在写入且新文件已创建，不代表触发静默等情形下已经收到全部类型的数据。界面可查看实际文件路径、输入连线和写入计数。

操作前后快照和结果只保存在本机 data/recording-operations；同步记录位于 data/stereo-sync。这些文件可能含真实序列号、路径及项目结构，默认不上传，公开反馈前必须自行脱敏。
